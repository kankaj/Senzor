# senzor-mcp

The MCP server of [Senzor](https://senzor.kankaj.cz), an MQTT sensor simulator: the tools and
reference pages through which an AI agent edits and runs a project.

It is published so that [`senzor`](https://crates.io/crates/senzor) and
[`senzor-cli`](https://crates.io/crates/senzor-cli) can be installed from crates.io. It has no
stable API of its own: it changes with Senzor, and its version always equals theirs.
